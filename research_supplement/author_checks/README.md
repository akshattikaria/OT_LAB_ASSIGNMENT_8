# Author reconstruction reference

qflair_reconstruction.py contains the unchanged determine_sine_curve and eq_sin functions extracted from QNN/QNN_cost.py in https://github.com/phels23/Q-FLAIR at commit 4f331783fc5bda5492fa3fffff0a845b0805eb39. The added header/import identifies the extraction. The original Apache-2.0 license is supplied in QFLAIR_LICENSE.txt. Authors: Jonas Jäger, Philipp Elsässer and Elham Torabian. These functions are used as an independent reference in tests, not represented as student-created algorithms.
