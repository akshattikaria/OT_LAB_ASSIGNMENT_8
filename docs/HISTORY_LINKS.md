# Public development-history links

All ten original track histories and the integration history have browsable **source-only archival reconstruction branches**. These are later archival imports: original source blobs are byte-for-byte unchanged, while public commit IDs and publication timestamps differ from the original bundle commits. Original hashes, dates and subjects are recorded below and in each snapshot's ARCHIVE_ORIGIN.json. No earlier development date or manual student edit is invented.

Large results/data/binaries and vendored/pristine trees are omitted from this browsing view. The complete original Git histories and all measured artifacts remain in the main project and its portable bundles. Track J's full bundle is restored from its two lossless parts with tools/restore_large_files.py. The source subset and original source hashes are explicitly recorded for every public snapshot.
