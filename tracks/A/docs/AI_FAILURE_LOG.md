# Genuine AI implementation failure: cancellation near a minimum

Date: 2026-10-31. Tool/model: ChatGPT, session-reported `gpt-6.1-sol`.

## Original defect

Original commit: `ec3d8b248890dcd3b7544082885158a272495bfc`.

The convex convergence control evaluated sqrt(1+x^2)-1 with `np.hypot(1,x)-1`. At x=1e-10 this returned exactly 0.0 in the observed environment, although the true positive loss is approximately 5e-21. Subtracting nearly equal floating-point values caused cancellation.

Detection: a precision check during figure review evaluated the old formula and its algebraically equivalent rationalized form at the same point. Recorded values were 0.0 and 5.0000000000000005e-21.

Effect: the supplementary control could report a zero objective gap prematurely near its optimum. This did not affect the ridge/MLP training losses or the 270 main run measurements.

## Correction and verification

Corrected commit: `b5d6cc9aa0038348244bbb2714d6738e85838e50`.

Use x^2/(sqrt(1+x^2)+1), implemented in `smooth_convex_value`. Added `test_small_positive_convex_loss_is_not_cancelled`, requiring a positive value and agreement with 5e-21. The 30-test suite passes. Only the affected supplementary landscape record and derived plots/report were regenerated; main measured training runs were retained.

Lesson: finite-difference tests of a model do not automatically validate every diagnostic calculation. Test limiting cases and numerically stable equivalents before interpreting a tiny objective as exact convergence.
